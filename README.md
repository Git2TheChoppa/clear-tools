# Clear Tools

Clear Tools sells one-time purchase software. No subscription.

## What we sell

ClearPaste is a Chrome extension for local clipboard history and a paste check before you send. One-time purchase.

Tab Declutter is a Chrome extension that closes tabs you are not using. One-time purchase.

## Privacy

ClearPaste and Tab Declutter run in the browser. Clipboard history stays on the device. We do not sell personal data. Purchases are processed by Stripe. Questions: softwaredev.tyler@gmail.com.

This repository is the public shop page only. Product source code is not here.
